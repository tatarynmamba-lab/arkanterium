ПЕПЕЛЬНЫЕ ЗЕМЛИ — ИНТЕРАКТИВНАЯ КАРТА RPG
============================================

Как запустить на Windows (БЕЗ установки сервера):
1. Распакуйте ZIP-архив в отдельную папку.
2. Дважды щёлкните по файлу ИГРАТЬ_БЕЗ_УСТАНОВКИ.html.
3. Выберите класс (Воин, Лучник, Маг) и создайте героя.
4. Откройте «Карта мира», нажмите на территорию и выберите противника.
5. После победы ингредиенты автоматически попадут в инвентарь.
6. В «Гильдиях» из ингредиентов создавайте оружие, броню и эликсиры.
7. В городе Рубеж можно бесплатно восстановить здоровье и ману.

Однофайловая версия содержит ВСЮ игру (домашний экран, карту, бой, гильдии).
Это основной рекомендуемый вариант для новичка.

Альтернативный вариант для дальнейшей разработки — отдельные страницы
index.html / map.html / battle.html / guilds.html с JS и CSS.
Для их совместной работы и надёжного общего сохранения через localStorage
используйте локальный HTTP-сервер (например, Live Server в VS Code).
Просто открывать index.html в разных браузерах можно, но сохранение между
отдельными file:// страницами зависит от ограничений конкретного браузера.

Файлы:
- ИГРАТЬ_БЕЗ_УСТАНОВКИ.html — ВСЯ игра в одном файле, без сервера;
- index.html  — создание персонажа и продолжение игры (многостраничная версия);
- map.html    — интерактивная карта, описание 7 территорий и 18 врагов;
- battle.html — пошаговые бои;
- guilds.html — 4 гильдии, рецепты, крафт;
- data.js     — ВСЕ данные классов, регионов, врагов и рецептов;
- app.js      — игровая логика, бои, случайные шансы, инвентарь;
- styles.css  — внешний вид (включая телефон и компьютер).

Прогресс автоматически сохраняется в localStorage браузера.
При смене браузера, режима «инкогнито» или очистке данных сохранение может пропасть.
Все выпадения с монстров — только ингредиенты, без готового снаряжения.
Карта является самостоятельной демонстрацией: для точного объединения с
предыдущим ZIP-проектом понадобятся его исходные файлы.

Как менять мобов: откройте data.js обычным текстовым редактором,
найдите раздел mobs и обновите характеристики или массив drops.
Каждая добыча записана как ["Название ингредиента", шанс в %, минимум, максимум].
