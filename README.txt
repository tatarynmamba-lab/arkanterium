АРКАНТЕРИУМ — МНОГОСТРАНИЧНАЯ ВЕРСИЯ 2.0

Это самостоятельная копия сайта из чата, на обычном JavaScript (Vanilla JS).
HTML отвечает за страницы, CSS — за оформление, JS — за взаимодействие.
Все файлы находятся в архиве. Внешних библиотек, CDN, сборки и npm install нет.

1. БЫСТРО ПОСМОТРЕТЬ

1) Скачайте ZIP и полностью распакуйте его.
   В Windows: правая кнопка по архиву → «Извлечь всё».
2) Зайдите в папку arkanterium-js.
3) Дважды нажмите index.html. Откроется браузер.
4) Нажимайте карточки и меню: каждый раздел имеет отдельную HTML-страницу.

Не открывайте index.html прямо внутри ZIP: сначала извлеките всю папку.
Не переносите HTML отдельно от папки assets.

При прямом открытии файлов браузер может разделять хранилище разных страниц
или запрещать его. Для профиля, заметок и поиска по заметкам используйте
локальный сервер по инструкции ниже.

2. ПОЛНЫЙ ЛОКАЛЬНЫЙ ЗАПУСК

Потребуется установленный Node.js. Проверьте командой: node --version
Если команда не найдена, установите Node.js с https://nodejs.org/.

Windows: дважды нажмите START-WINDOWS.bat, затем откройте в браузере:
http://localhost:8080

Windows, macOS или Linux — альтернативный запуск:
1) Откройте терминал в папке arkanterium-js.
2) Выполните команду: node server.js
   Можно также использовать: npm start
3) Откройте http://localhost:8080
4) Оставьте терминал открытым, пока пользуетесь сайтом.
   Остановить сервер: Ctrl+C.

Если порт 8080 занят:
node server.js --port 8081
Тогда адрес: http://localhost:8081

Всегда используйте один и тот же адрес и порт, чтобы видеть свои заметки.
localhost и 127.0.0.1 считаются разными адресами для хранения данных.

3. ПРОВЕРИТЬ НА ТЕЛЕФОНЕ

1) Компьютер и телефон должны быть подключены к одной доверенной Wi-Fi-сети.
2) На компьютере остановите прежний сервер через Ctrl+C.
3) В папке проекта выполните: node server.js --lan
   Можно также использовать: npm run mobile
4) В терминале появится «Адрес для телефона», например http://192.168.1.5:8080.
5) Откройте именно показанный адрес в браузере телефона.
   Не используйте localhost на телефоне: это адрес самого телефона.
6) Если система спросит разрешение для Node.js, разрешите доступ в частной
   сети. Не отключайте брандмауэр целиком.

Компьютер и сервер должны оставаться включёнными. Некоторые гостевые Wi-Fi
сети запрещают связь между устройствами. Режим --lan открывает доступ всем
устройствам, которым доступен ваш компьютер в локальной сети, без авторизации.
Для обычной работы на одном компьютере запускайте node server.js без --lan.
Заметки и профиль телефона не синхронизируются с компьютером.

4. ЧТО РАБОТАЕТ

index.html   — главная: адаптивное меню, приветствие и карточки-ссылки.
profile.html — локальный профиль: имя, бизнес и описание.
notes.html   — создание, изменение, удаление и скачивание заметок в TXT.
files.html   — выбор файлов, размер, удаление из списка; файлы не загружаются.
search.html  — поиск по разделам и локальным заметкам, переход к заметке.
chats.html   — демонстрационный помощник с ответами по заданным правилам.
login.html   — страница с объяснением статуса входа и аккаунтов.

Это не готовая многопользовательская платформа. Регистрация, настоящий вход,
права администратора, чат между людьми, ИИ-бот и серверное хранение файлов
пока не подключены. Пароли и платёжные данные сайт не запрашивает.

Профиль и заметки сохраняются в localStorage текущего браузера.
После очистки данных браузера они могут исчезнуть. Скачивайте копию заметок.
Переписка с демопомощником и список файлов существуют только на текущей странице.

Заметка из первой версии автоматически подхватывается, если сайт открыт
в том же браузере и по тому же адресу. Данные с опубликованного сайта
не копируются автоматически в локальную версию.

5. ГДЕ ИЗМЕНЯТЬ КОД

Страницы (*.html)              — тексты и структура разделов.
assets/css/styles.css          — оформление, цвета и адаптация для телефона.
assets/js/app.js               — общее меню и поведение всех страниц.
assets/js/storage.js           — локальное хранение профиля и заметок.
assets/js/profile.js           — работа с профилем.
assets/js/notes.js             — создание, редактирование и экспорт заметок.
assets/js/files.js             — выбор и список файлов.
assets/js/search.js            — поиск по разделам и заметкам.
assets/js/chats.js             — демонстрационный помощник.
assets/js/index.js, login.js   — точки расширения главной и страницы входа.
server.js                     — локальный сервер на JavaScript / Node.js.

Чтобы изменить цвет акцента, найдите --purple в assets/css/styles.css.
После редактирования сохраните файл и обновите страницу браузера.

Файлы проекта не содержат ключей доступа к хостингу, зависимостей node_modules
или истории Git. Архив можно перенести на обычный статический хостинг.
Для публикации загружаются HTML и папка assets; локальный server.js для этого
не требуется. Архив сам по себе не меняет ранее опубликованный сайт.

6. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

Нет оформления — проверьте, что распакована вся папка assets.
Ничего не сохраняется — используйте локальный сервер и обычный режим браузера.
Поиск не видит заметки — проверьте, что страницы открыты по одному адресу/порту.
Телефон не открывает — проверьте Wi-Fi, адрес из терминала и запущенный сервер.

Проверки при сборке: синтаксис JS, целостность HTML-ссылок и путей,
чтение/запись локальных данных, ответы локального сервера, целостность ZIP.
Визуальная проверка в браузере в среде сборки не выполнялась.
