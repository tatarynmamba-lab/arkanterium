# Ведьмак: Тропа охотника — JS, версия 3.1

Многостраничная одиночная RPG. Игра и локальный сервер написаны на обычном JavaScript. Сборка, npm и сторонние пакеты не нужны.

## Запуск на Windows

1. Скачай ZIP и выбери «Извлечь всё». Не запускай игру внутри архива.
2. Установи Node.js, если он ещё не установлен. После установки при необходимости перезапусти проводник или компьютер.
3. Открой папку `vedmak-js` и дважды нажми `start.bat`.
4. Браузер откроется автоматически. Если этого не произошло, введи в адресную строку **http://localhost:8080**.
5. Оставь окно запуска открытым, пока играешь. Чтобы остановить сервер, нажми Ctrl+C.

## macOS и Linux

Установи Node.js. В терминале перейди в распакованную папку и выполни:

```sh
sh start.sh
```

Или на любой системе:

```sh
node server.js
```

Открой http://localhost:8080. Сервер раздаёт файлы игры с твоего компьютера; он не публикует её в интернете.

## Если не открывается

- Проверь, что архив распакован и рядом со `start.bat` находится `server.js`.
- Если написано, что нужен Node.js, установи его и снова запусти `start.bat`.
- Если порт занят, закрой окно другого сервера. Или в Windows открой терминал в папке игры и выполни `set PORT=8081`, затем `node server.js`; адрес станет http://localhost:8081.
- Открытие `index.html` напрямую может показать игру, но браузеры по-разному сохраняют данные для файлов. Для общего прогресса между страницами используй запуск через сервер.
- Если браузер блокирует данные сайта, появится предупреждение. Разреши сохранение для адреса игры.

## Проверка на телефоне

Подключи компьютер и телефон к одной Wi-Fi сети. На компьютере в терминале папки игры выполни `node server.js --lan`. Узнай локальный IPv4 компьютера (Windows: `ipconfig`) и открой на телефоне `http://IP-КОМПЬЮТЕРА:8080`, например `http://192.168.1.25:8080`. Если система спрашивает доступ к сети, разреши его для своей домашней сети. Окно сервера должно оставаться открытым. `localhost` на телефоне означает сам телефон, поэтому для компьютера используй его IPv4.

На телефоне будет отдельное сохранение. Перенести его можно через «Журнал» → «Скачать сохранение» и «Загрузить сохранение JSON».

## Стартовый город

Новая игра начинается на городской площади Оксенфурта. Это безопасная локация: в городе нет случайных боёв. На странице «Город» доступны таверна, лавка эликсиров, снаряжение и доска контрактов. Первый городской заказ отправляет тебя в Белый Сад. Нажми «Выйти на охоту» или кнопку перехода к месту контракта, а затем «Идти по следу». Вернуться в город можно через карту или страницу города вне боя. После поражения герой очнётся в городской таверне; возвращение само по себе не восстанавливает всё здоровье.

Старые сохранения и контракты сохраняют свои локации. Чтобы попасть в город с текущим героем, выбери «Город» → «Войти в город»; начинать заново не требуется. Кнопка «Новая игра» создаёт нового героя в Оксенфурте и удаляет текущий прогресс после подтверждения.

## Как играть

В городе возьми контракт, выйди к месту охоты и нажми «Идти по следу» и сражайся. Быстрый удар даёт 1 энергию; Игни и Квен тратят по 2. Игни наносит урон, Квен поглощает следующую атаку. Сильный удар может промахнуться. «Ласточка» восстанавливает здоровье, но в бою после неё противник отвечает. Контракт оплачивается автоматически после победы над целью в нужной локации. Отдых и смена экипировки в бою недоступны.

Победы дают опыт, кроны и иногда снаряжение. С ростом уровня открываются новые локации. Надевай трофеи на странице инвентаря.

## Сохранение

Состояние общее для всех страниц на одном адресе и автоматически записывается в localStorage браузера, включая незавершённый бой. Используй один и тот же браузер и адрес (`localhost` и `127.0.0.1` имеют разные сохранения). Смена порта также создаёт другой адрес. Очистка данных браузера удаляет прогресс. Для резервной копии скачай JSON в журнале. Загружаемый файл проверяется до замены прогресса.

Сохранение прежнего HTML-прототипа подхватится, если он запускался на том же адресе и порту. При прямом открытии старого файла оно обычно недоступно новому серверу. Эта версия не содержит аккаунтов, многопользовательского режима или синхронизации через интернет.

## Структура кода

- `assets/js/data.js` — локации, враги и снаряжение.
- `assets/js/engine.js` — правила боя, контракты, прокачка и сохранение.
- `assets/js/app.js` — отображение и обработка кнопок на страницах.
- `assets/css/style.css` — общий адаптивный стиль.
- `server.js` — локальный HTTP-сервер на Node.js.
- `tests/` — проверки логики, страниц и локального сервера. Запуск: `node --test tests/*.test.js`.

При подготовке архива пройдены автоматические проверки правил игры, сохранений, ссылок страниц, инициализации интерфейса и HTTP-сервера. Визуальная проверка в браузере в этой среде не выполнялась.

Неофициальный бесплатный фанатский учебный проект по мотивам «Ведьмака». Не связан с правообладателями. Без официальных изображений и музыки.
